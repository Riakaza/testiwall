Comment construire le bot avec Python

Un bot Vinted minimal utilise httpx pour les requêtes, BeautifulSoup pour le parsing HTML, et discord.py pour les alertes. La partie difficile, c'est le bypass de la protection anti-bot (Vinted utilise des tokens CSRF et rate-limiting).

Les bibliothèques essentielles :

  • playwright — navigation navigateur pour éviter la détection
  • httpx — requêtes HTTP avec gestion des cookies
  • sqlite3 — base de données locale pour éviter les doublons
  • discord-webhook — alertes instantanées

Le cycle principal :

  1. Authentification avec session valide
  2. Requête API Vinted /api/v2/catalog/items avec filtres prix/catégorie
  3. Déduplication via la base de données locale
  4. Calcul de marge estimée
  5. Notification Discord si marge > seuil
  6. Achat automatique si prix < seuil d'achat immédiat
⚠️ Les bots Vinted sont contraires aux CGU de la plateforme. Utilisation à titre personnel uniquement.
